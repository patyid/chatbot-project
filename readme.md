# Projeto Chatbot com Streamlit + LangChain + Ollama

Este é um projeto de chatbot desenvolvido usando Streamlit, LangChain e Ollama. O chatbot permite que os usuários interajam com um assistente inteligente por meio de uma interface de chat.

## Requisitos

Antes de começar, certifique-se de ter os seguintes requisitos instalados:

- Python 3.x
- Streamlit
- LangChain
- Ollama
